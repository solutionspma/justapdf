# JustaPDF

PDF generation engine for the Pitch ecosystem.

## Status

🔧 In Development

## Overview

JustaPDF provides PDF generation capabilities for other platforms in the ecosystem. It's designed as a shared service rather than a standalone user-facing platform.

## Structure

```
justapdf/
├── contracts/           # Platform contracts
├── docs/               # Documentation
├── backend/            # Server logic
├── config/             # Configuration
├── engines/            # PDF generation engines
├── netlify/            # Deployment config
└── public/             # Static assets
```
